# Data Engineering Analytics Pipeline

End-to-end data engineering project demonstrating:

- Advanced SQL and star-schema data modeling
- Python-based ETL with incremental and idempotent loads
- Cloud-style architecture using S3 and relational warehouse concepts

## Architecture
Source Data → Python ETL → Data Lake → Warehouse → Analytics SQL

## Key Features
- Incremental data processing
- SCD Type 2 customer tracking
- Data quality validation
- Analytics-ready warehouse design
